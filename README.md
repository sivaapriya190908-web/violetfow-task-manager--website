# violetfow-task-manager--website
💜 Violet Flow — Task Manager

A modern and intuitive task management web application designed to help users organize their tasks, set priorities, and stay productive.

✨ Features

- 📝 Create and manage tasks
- 🎯 Organize tasks based on priority
- ✅ Mark tasks as completed
- 🗑️ Delete tasks when they are no longer needed
- 📱 Responsive and user-friendly interface
- 🎨 Modern Violet-themed UI
- ⚡ Simple and intuitive task organization

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
